# Data usage

- Repository-authored code and documentation use the MIT license.
- Third-party auxiliary data retain their providers' terms; repository publication does not relicense the source products.
- In-situ soil-moisture observations and associated provider metadata are not redistributed because the applicable source-data terms restrict onward distribution.
- Record-level model predictions and trained weights are not included in this release.
- Auxiliary input examples use anonymous identifiers and privacy-shifted timestamps. Their scientific values and relative time intervals are preserved.
- Source acknowledgments and product links are listed in [data sources](metadata/data_sources.md).
